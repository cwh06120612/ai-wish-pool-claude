# 更新紀錄

## 2026-07-28

### 「暫不處理」也算結案
- 需求狀態新增**結案**的概念：**已導入**（有解法落地）與**暫不處理**（評估後先不做）都算結案，只是結果不同；兩者都不再算「處理中」。
- **成果看板**：第 4 張 KPI 由「導入完成率」改為「**已結案率**」（＝（已導入＋暫不處理）÷ 總需求數，維持百分比呈現），副標顯示已結案件數與其中暫不處理幾件。
- **成果看板**新增「**評估後暫不處理**」清單區塊（只列公開的需求），每則附上數位創新處的處理說明；未填說明時顯示提示語。區塊底部說明「暫不處理不代表不重要，情況有變會重新開案」。
- **公告欄**詳情頁：暫不處理的需求不再顯示「這則需求還在處理中」，改為「**這則需求評估後暫不處理，已先結案**」，仍可點「討論這則需求」補充新資訊。
- 由暫不處理需求自動建立的討論串，預設說明文字改為結案版本（原本會誤寫成「還在處理中」）。
- **管理後台**：狀態篩選新增「**未結案**」「**已結案（已導入＋暫不處理）**」兩個群組選項；狀態流程圖中「已導入 → 暫不處理」的箭頭改為「或」，並在下方標註已結案件數。

## 2026-07-09
