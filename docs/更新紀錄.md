# 更新紀錄

## 2026-07-09

### 用字統一：回饋 → 評論
- 成果看板、公告欄、管理後台的「回饋」一律改為「**評論**」。
- 保留「同仁怎麼說」「你的評價」等既有貼切用語。

### 公告欄 × 主題討論連動
- 公告欄**未導入**需求移除評分框，改為「**討論這則需求**」。
- 點擊自動取得／建立該需求對應的討論串（`topics` 新增 `submission_id` 綁定、含 unique index），使用者只需留言、不會重複開串。
- 主題討論列表／串頁標示「需求討論」「來自公告欄需求」。
- 新增一次性搬遷 SQL：把未導入需求上「有文字」的舊評論搬到主題討論，純星等評論清除。

### 主題作者顯示
- 修正需求衍生主題「數位創新處」名字與皇冠膠囊重複、窄卡片折行的問題。
- 還原頭像旁人名顯示（列表卡片、串頁標頭、每則留言）。
- 官方主題／留言**無具體負責人員時，頭像旁統一顯示「管理者」**（並附「數位創新處」標記）。

### 版面與樣式
- 導覽列、公告欄、主題討論、管理後台主內容區加寬至 **1120px**、彼此對齊。
- 公告欄卡片大螢幕最多 4 欄；主題討論列表定為一排最多 **3 欄**、卡片收扁、標題最多兩行截斷。
- 主題卡片「需求討論」標籤與 icon 改用**副色**（棕）以資區別；移除標籤前的圖示。
- 移除成果看板底部「還有讓你頭痛的事嗎？」CTA 區塊。

### 主題討論操作
- 新增「**需求討論**」篩選標籤（搜尋列下方，分段：全部／需求討論，預設全部）。
- 新增排序切換（**由新至舊／由舊至新**），與公告欄共用同一個 `InlineFilterDropdown` 元件。

### 其他
- 新增 `Linkify`：留言／評論／主題說明中的網址自動轉為可點連結（新分頁開啟）。
